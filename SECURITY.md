# Security Policy

[English](#english) · [Türkçe](#türkçe) · [Español](#español)

---

## English

### Supported versions

Only the [latest release](https://github.com/unseensenpai/onepace-utilities/releases/latest) receives fixes.

### Reporting a vulnerability

[Open an issue](https://github.com/unseensenpai/onepace-utilities/issues/new/choose) describing the problem and the affected version. Do not post working exploit code or personal data in the issue. If more detail is needed, the maintainer will reply there.

The extension stores progress and settings only in your browser's extension storage and does not send them anywhere.

## Türkçe

### Desteklenen sürümler

Düzeltmeler yalnızca [en son sürüme](https://github.com/unseensenpai/onepace-utilities/releases/latest) gelir.

### Güvenlik açığı bildirme

Sorunu ve etkilenen sürümü anlatan bir [issue aç](https://github.com/unseensenpai/onepace-utilities/issues/new/choose). Issue'ya çalışan istismar kodu veya kişisel veri yazma. Daha fazla ayrıntı gerekirse proje sahibi orada yanıt verir.

Eklenti ilerlemeni ve ayarlarını yalnızca tarayıcının eklenti depolamasında tutar, hiçbir yere göndermez.

---

## Español

### Versiones compatibles

Solo la [última versión](https://github.com/unseensenpai/onepace-utilities/releases/latest) recibe correcciones.

### Informar de una vulnerabilidad

[Abre un issue](https://github.com/unseensenpai/onepace-utilities/issues/new/choose) describiendo el problema y la versión afectada. No publiques código de explotación funcional ni datos personales en el issue. Si hace falta más información, el mantenedor responderá allí.

La extensión guarda el progreso y los ajustes solo en el almacenamiento de extensiones de tu navegador y no los envía a ningún sitio.
