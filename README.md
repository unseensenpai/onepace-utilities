# OnePace Utilities

OnePaceTR için Arc Master, bölüm bazlı izleme ilerlemesi ve kalıcı oynatıcı tercihleri sunan Chromium extension.

## Kurulum

1. GitHub Releases bölümünden `onepace-utilities.zip` dosyasını indirip bir klasöre çıkar.
2. Chromium tabanlı tarayıcında uzantılar sayfasını aç ve Developer Mode'u etkinleştir.
3. `Load unpacked` ile çıkarılan klasörü seç.

## Geliştirme

```sh
npm test
```

`v*` biçimindeki bir Git tag'i GitHub'a push edildiğinde otomatik ZIP ve GitHub Release oluşturulur.
